# Algorithm Visualizer Lab

a interactive data structures and algorithms learning website project.

## Project Context

- Domain: `interactive data structures and algorithms learning website`
- Primary user: `students learning data structures and algorithm design`
- MVP focus: `explore sorting and array algorithms with editable inputs and step-by-step visualization`

## Development Workflow

This project uses a PRD-first, task-based AI-assisted development workflow.

1. Read `AGENTS.md` and the relevant project rules.
2. Confirm the PRD and task scope.
3. Implement one small complete task.
4. Run verification.
5. Review the diff and prepare a human handoff.

## Verification

```bash
bash scripts/verify.sh --instance
bash scripts/verify.sh --strict-instance
```

See `docs/harness/06-strict-readiness.md` for the readiness checklist.

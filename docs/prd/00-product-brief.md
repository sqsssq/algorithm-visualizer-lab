# Product Brief

## Summary

`Algorithm Visualizer Lab` is a interactive data structures and algorithms learning website project.

## Product Context

- Domain: `interactive data structures and algorithms learning website`
- Primary user: `students learning data structures and algorithm design`
- Primary user problem: `Students can see an algorithm's final result but struggle to connect each code operation with the changing data structure state.`
- MVP focus: `explore sorting and array algorithms with editable inputs and step-by-step visualization`

## Product Promise

`The product makes algorithm execution inspectable: students can edit inputs, move through one deterministic step at a time, and connect visual changes with explanations and pseudocode.`

## Success Criteria

The MVP succeeds when:

- `A student can edit an input array and reset the visualization from that input.`
- `A student can play, pause, step forward, and step backward through a sorting algorithm.`
- `Every visible step identifies the operation, affected elements, and corresponding pseudocode line.`
